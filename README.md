# PaddleWaver Korea

PaddleWaver 한국 지사 웹사이트 디자인 시안 (프론트엔드 전용, 정적 사이트).

- `index.html` : 시안 선택 페이지
- `v1/` : 시안 1 Bright Gradient (홈, 앱 리타게팅, CTV)
- `v2/` : 시안 2 Editorial Mono (홈, 앱 리타게팅, CTV)
- `imgs/` : 공용 이미지, `proposals/` : 시안 썸네일
- 스택: HTML + CSS + GSAP ScrollTrigger 3.12.5 + Lenis 1.1.13 (CDN, 빌드 없음)
- 반응형: Mobile ~767 / Pad 768~1279 / PC 1280~

시안 추가: `v3/` 폴더를 만들고 `index.html`의 카드 블록을 하나 복사해 링크와 썸네일만 바꾸면 됩니다.
