# PaddleWaver Korea

PaddleWaver 한국 지사 웹사이트 (프론트엔드 전용, 정적 사이트).

- 페이지: `index.html` (UA 마케팅), `app-retargeting.html`, `ctv.html`
- 스택: HTML + CSS + GSAP ScrollTrigger 3.12.5 + Lenis 1.1.13 (CDN, 빌드 없음)
- 반응형: Mobile ~767 / Pad 768~1279 / PC 1280~
- 로컬 실행: `index.html`을 브라우저로 열거나 `python -m http.server`
